    AirPoint

    Point in the air, and it clicks.

    Computer vision

    A mouse controlled by hand, built with Python, OpenCV, and MediaPipe: the cursor follows my hand and pinch gestures click, with no hardware in between. The same tracking also plays Hill Climb Racing, with steering and acceleration mapped to hand gestures.

    • Python
    • OpenCV
    • MediaPipe
    GitHub

  4. 04 / 06

    Swarm

    Pinch the air, and it flows.

    Interactive visuals

    A GPU-rendered swarm of particles that follows both hands in real time: two-handed pinch gestures pull it into flowing, looping patterns. Hand tracking runs on OpenCV and MediaPipe, and the particles render with ModernGL.

    • Python
    • OpenCV
    • MediaPipe
    • ModernGL
    GitHub
